# Pannello Shader impostazioni

![](../../assets/Shader-settings-panel-gen.png.img.png)

Nel <b>pannello Shader</b> è possibile configurare il modo in cui lo shader esegue il rendering delle risorse sulla trama nella finestra della vista 3D.

## Parametri del materiale

I parametri dei materiali consentono di regolare il modo in cui viene eseguito il rendering del materiale corrente da parte dello shader.

| Nome parametro | Descrizione |
| --- | --- |
| Scala normale | Regolate l’intensità della mappa normale. |
| Combina normale e altezza | Attiva o disattiva la combinazione di Height e mappa normale in un&#39;unica mappa. |
| Livello di altezza | Modifica il livello di base del height per lo spostamento. |
| Intensità dell&#39;emissione | Regolate l’intensità delle mappe emissivi. |
| Dispersione sotto la superficie | Attivate o disattivate la dispersione sottosuperficie. |
| Indice di rifrazione | Regolate l&#39;angolo di rifrazione della luce sulle superfici. |
| Indice di rifrazione del rivestimento | Regolate l’angolo di rifrazione della luce sul rivestimento della superficie. |
| Scala Normal del rivestimento | Regolate la scala normale in modo specifico per il rivestimento della superficie. |
