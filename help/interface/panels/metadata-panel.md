# Pannello Metadati

![](../../assets/Metadata-panel-gen.png){width="500px"}

Nel pannello Metadati, potete accedere e modificare i metadati della risorsa.

<b>Nome</b>: il nome della risorsa.

<b>Descrizione</b>: descrizione della risorsa o della descrizione incorporata nel materiale di Substance

<b>Categoria</b>: categoria della risorsa o della categoria incorporata nel materiale di Substance

<b>Autore</b>: autore della risorsa o autore incorporato nel materiale di Substance. Per impostazione predefinita, il nome dell’autore corrisponde al nome dell’account del sistema operativo.

<b>Data di creazione</b>: data di creazione della risorsa in Sampler o data di importazione in Sampler. (Non può essere modificato)

<b>Data aggiornamento</b>: ultima data di aggiornamento della risorsa. (Non può essere modificato)

<b>Tag</b>: tag della risorsa o dei tag incorporati nel materiale di Substance.

<b>Dimensioni fisiche</b>: dimensioni X, Y e Z della risorsa.

<b>Valutazione</b>: valutazione della risorsa.

## Metadati personalizzati

Tutti i metadati personalizzati saranno inclusi nel file di materiale (SBSAR) per garantire un flusso di lavoro più efficiente per la condivisione di materiali digitali tra le applicazioni.

![](../../assets/Metadata-panel-Custom.png){width="350px"}

<b>Nuovo campo di testo </b> (aggiungere un campo personalizzato per i metadati):

1. Inserire il nome. Il nome di un metadati personalizzato deve essere un nome di elemento XML valido (ad esempio: senza spazi o caratteri speciali, non inizia con un numero...)
1. Inserisci descrizione/nota

Per modificare i campi dei metadati personalizzati, passa il cursore sul campo e seleziona il pulsante Modifica o Elimina visualizzato.
