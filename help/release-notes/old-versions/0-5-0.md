# 0.5.0

Data di pubblicazione: **2019/02/28**

Aggiunto:

* [Pila livelli] Riordinamento dei livelli
* [Pila livelli] Eliminare un livello nascosto
* [Pila livelli] Importa un materiale direttamente nella posizione desiderata
* [Pila livelli] Immissione materiale come nuovo tipo di parametro del filtro
* [Prestazioni] Il budget Substance Engine è dinamico per prestazioni migliori
* [Prestazioni] Migliori prestazioni OpenGL, in particolare su MacOS
* [Data] Aggiornamento dei dati più rapido dopo il rilascio di una nuova versione
* [Content] AI Delighter disponibile su Windows 7 e Windows 8
* [Content] AI Delighter disponibile sulla GPU RTX

Fisso:

* Correggere possibili arresti anomali all’uscita dall’applicazione
* L’esportazione della finestra a comparsa si apre più rapidamente durante l’esportazione di raccolte di grandi dimensioni

Problemi noti:

* L&#39;uso di più delighters in un unico materiale non è raccomandato
* Arresti anomali più gradevoli con driver NVIDIA meno recenti (meno di 400.x)
* L&#39;interruttore di visibilità rapida di uno stadio Delighter influirà sulle prestazioni
* Arresto anomalo durante il caricamento del proprio ambiente
