# Variabili di ambiente

Questa pagina elenca le variabili di ambiente che possono essere utilizzate per ignorare il comportamento predefinito dell&#39;applicazione.

| Variabile | Descrizione |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_LICENSE** | Valore: percorso del file license.keyIgnora il percorso da cui l&#39;applicazione carica il file di licenza.  **Nota:** le versioni precedenti alla 3.0 utilizzano invece questo nome di variabile:**SUBSTANCE\_ALCHEMIST\_LICENSE** |
