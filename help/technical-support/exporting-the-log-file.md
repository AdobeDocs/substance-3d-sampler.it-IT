# Esportazione del file di registro

Quando hai bisogno di supporto per Substance 3D Sampler, è sempre consigliabile condividere il file di registro in quanto fornisce il contesto della configurazione del computer.

## Esportazione del file di registro dall&#39;applicazione

Il file di registro può essere esportato direttamente da Substance3D Sampler scegliendo **Aiuto** dal menu e selezionando l&#39;elemento **Esporta file di registro**.

![](../assets/export-log.jpg)

## Recupero manuale del file di registro sul disco

Se non riesci ad avviare Substance 3D Sampler, puoi recuperare manualmente il file di registro nella seguente cartella:

Versione di Adobe:

* **Windows**: C:\Users\**&#x200B; nome utente**\AppData\Local\Adobe\Adobe Substance 3D Sampler\log.txt
* **Mac OS**: Macintosh > Utenti > **nome utente** > Libreria > Supporto applicazioni > Adobe > Adobe Substance 3D Sampler > log.txt

Versione Substance3D:

* **Windows**: C:\Users\**&#x200B; nome utente**\AppData\Local\Allegorithmic\Adobe Substance 3D Sampler\log.txt
* **Mac OS**: Macintosh > Utenti > **nome utente** > Libreria > Supporto applicazioni > Allegorithmic > Adobe Substance 3D Sampler > log.txt
* **Linux**: /home/**nomeutente**/.local/share/Allegorithmic/Adobe Substance 3D Sampler/log.txt

>[!NOTE]
>
> In **Windows** &quot;Appdata&quot; è una cartella nascosta.\
> In **Mac OS** la &quot;libreria&quot; è una cartella nascosta.\
> In **Linux** &quot;.local&quot; è una cartella nascosta.

## Allegare il file di registro a un post del forum

Quando richiedi supporto sul forum, è richiesto un file di registro. Di seguito viene descritto come allegare un file di registro al messaggio:

1. Verifica l&#39;impostazione &quot;**Partecipa a un file**&quot;
1. Fai clic sul pulsante &quot;**Scegli file**&quot; e individua il file di registro.
1. Fai clic su &quot;**Post**&quot; quando il messaggio è pronto per pubblicare e caricare il file di registro
