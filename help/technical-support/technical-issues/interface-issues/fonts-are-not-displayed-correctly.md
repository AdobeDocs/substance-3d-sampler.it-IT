# I font non vengono visualizzati correttamente

Se utilizzi Windows 10 Enterprise e la [funzionalità Blocca font non affidabili](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise), puoi seguire questa [esercitazione](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html) per escludere Sampler dall&#39;elenco delle app non attendibili per il blocco dei font.
