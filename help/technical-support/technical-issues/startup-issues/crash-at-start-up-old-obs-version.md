# Arresto anomalo all’avvio - Versione OBS precedente

È possibile che l&#39;applicazione si arresti anomali all&#39;avvio a causa di una versione precedente di [OBS](https://obsproject.com/fr) installata.

Per risolvere questo problema, aggiorna [OBS versione](https://obsproject.com/fr/download) o disinstalla.
