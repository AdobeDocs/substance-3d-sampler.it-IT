# Verifica aggiornamenti

Nella finestra Aggiorna viene indicato se è disponibile una nuova versione di Substance Alchemist e vengono visualizzate anche le [Note sulla versione](../../release-notes/release-notes.md) più recenti.

Questa finestra viene visualizzata automaticamente all&#39;avvio di Substance Alchemist se è disponibile una nuova versione da scaricare.

È possibile evitare di visualizzare questa finestra durante l&#39;avvio con i seguenti metodi:

* Utilizzare l&#39;impostazione &quot;Non visualizzare alcun promemoria fino alla versione successiva&quot; nella finestra per ignorare temporaneamente la visualizzazione della finestra fino alla versione successiva.
* Disabilita l&#39;impostazione &quot;**Ricerca aggiornamenti**&quot; in Modifica > Preferenze > Ricerca aggiornamenti
* Utilizzo della riga di comando **—skip-version-check** Non verrà verificato se una nuova versione dell&#39;applicazione è disponibile all&#39;avvio di Substance Alchemist
* Utilizzo di una variabile di ambiente **SUBSTANCE\_ALCHEMIST\_SKIP\_CHECK\_FOR\_UPDATES**:Value 0 o 1 (1 = Disattiva controllo aggiornamento)

>[!NOTE]
>
> Supportato dalla Substance Alchemist 2020.1 (2.1)
