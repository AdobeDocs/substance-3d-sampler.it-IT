# Configurazione del capture 3D su Linux

Per utilizzare <b>capture 3D</b> su Linux è necessario installare <b>Wine 8</b> con un account amministratore.

Ubuntu

apt-get install wine

Red Hat Enterprise Linux (RHEL 8)

repo sudo subscription-manager: abilitazione di codeready-builder-for-rhel-8-x86\_64-rpms

dnf install wine

Red Hat Enterprise Linux (RHEL 9)

repo sudo subscription-manager: abilitazione di codeready-builder-for-rhel-9-x86\_64-rpms

dnf install wine
