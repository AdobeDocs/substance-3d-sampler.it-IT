## Parametri

**Parametri di base**

* **Modalità destinazione**:\
  Scegliete se far corrispondere il materiale di input o i parametri personalizzati. I parametri disponibili dipendono dalla modalità di **destinazione** selezionata.
  * **Input**
    * **Raggio**: 0-50\
      Regola il raggio dell’area corrispondente
    * **Predefiniti**:\
      Seleziona se abbinare solo il colore o entrambi colore e rugosità. Questa selezione modifica le opzioni disponibili in **Parametri avanzati**
  * **Parametro**
    * **Predefiniti**:\
      Seleziona se abbinare solo il colore o entrambi colore e rugosità. Questa selezione modifica le opzioni disponibili in **Parametri avanzati**
    * **Colore di base**: selezione colore\
      Seleziona il colore corrispondente
    * **Rugosità**: 0-1\
      Imposta la rugosità in base a

**Parametri avanzati**

* **Input affiancato**: attiva/disattiva\
  Abilita questa opzione se le porzioni di input consentono di migliorare la corrispondenza ai bordi del materiale
* **Colore di base - Destinazione corrispondente**: 0-1\
  Regola l’intensità della corrispondenza del colore di base
* **Rugosità - Destinazione corrispondente**: 0-1\
  Regola la durezza della corrispondenza di rugosità
