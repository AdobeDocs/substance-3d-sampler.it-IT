# Gestione dei predefiniti

I predefiniti consentono di configurare rapidamente il file esportato per una determinata applicazione. Se utilizzate una pipeline non coperta dai predefiniti predefiniti, potete anche creare dei Predefiniti personalizzati che soddisfino le vostre esigenze.

## Usa predefiniti

I predefiniti sono disponibili solo quando esportate in un file di immagine. Quando esporti in SBS o SBSAR, i predefiniti non sono necessari.

Per accedere a Predefiniti:

1. Apri la finestra <b>Esporta </b>:
   1. Utilizza il <b>pannello Esportazione</b> nella <b>barra destra</b>.
   1. Usa <b> File > Esporta come...</b>
   1. Usa scelta rapida da tastiera <b>Ctrl + E.</b>
1. Nella parte sinistra della finestra <b>Esporta </b>, seleziona <b>Impostazioni materiale</b>.
1. Selezionare un formato di immagine (EXR, JPEG, PNG, TARGA, TIFF)
1. Viene visualizzato l’elenco dei predefiniti.

![](../../assets/Managing-presets-Dropdown.png.img.png){width="400px"}

Utilizza il menu a discesa Predefiniti per selezionare un predefinito oppure utilizza il pulsante <b>Gestisci predefiniti </b> accanto al menu a discesa per gestire i predefiniti.

## Gestisci predefiniti

Utilizza il menu a discesa Predefiniti per selezionare un predefinito oppure utilizza il pulsante <b>Gestisci predefiniti </b> accanto al menu a discesa per gestire i predefiniti.

## Predefiniti preimpostati

![](../../assets/Managing-presets-Window.png.img.png){width="400px"}

Per tutti i predefiniti di default, potete attivarli/disattivarli. Se un predefinito predefinito è disattivato, non sarà visibile nell’elenco a discesa Predefinito.

Per impostazione predefinita, tutti i predefiniti sono attivati.

## Predefiniti personali

Potete attivare/disattivare i predefiniti personalizzati. Se un predefinito personalizzato viene disattivato, non sarà visibile nell’elenco a discesa Predefinito.

Puoi anche:

* <b>Rinomina</b>: modificate il nome del predefinito nell&#39;interfaccia.
* <b>Sostituisci</b>: sostituisci il file del predefinito con una nuova versione.
* <b>Elimina</b>: eliminate il predefinito.
