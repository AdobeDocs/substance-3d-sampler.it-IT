# Scelte rapide

In questa pagina sono elencate tutte le scelte rapide da tastiera disponibili e le relative azioni.

## Scelte rapide globali

| *Azione* | *Windows* | *MacOS* |
| --- | --- | --- |
| Annulla | Ctrl + Z | ⌘ + Z |
| Ripristina | Ctrl + Maiusc + Z | ⌘ + Maiusc + Z |
| Salva | Ctrl + S | ⌘ + S |
| Salva con nome | Ctrl + Maiusc + S | ⌘ + Maiusc + S |
| Esporta | Ctrl + E | ⌘ + E |
| Solo vista 3D | 3 | 3 |
| Solo vista 2D | 2 | 2 |

## Scelte rapide della vista 3D

| *Azione* | *Windows* | *MacOS* |
| --- | --- | --- |
| Rotazione fotocamera | Alt + Mouse a sinistra o Mouse a sinistra | Opzione + Mouse a sinistra o Mouse a sinistra |
| Panning fotocamera | Alt + mouse centrale o mouse centrale | Opzione + Mouse al centro o Mouse al centro |
| Zoom fotocamera | Alt + Mouse a destra o rotellina del mouse | Opzione + Mouse a destra o rotellina del mouse |
| Messa a fuoco | F | F |
| Rotazione dell&#39;ambiente | Maiusc + Mouse a destra | Maiusc + Mouse a destra |
| Visibilità ambiente | 1 | 1 |
