# Importa le risorse

Sampler può utilizzare risorse esterne come immagini e file di Substance per modificare il progetto. Utilizza una delle seguenti opzioni per importare un file nel progetto:

* Trascina un file da Esplora file alla finestra di Sampler. Viene visualizzata una finestra di importazione con opzioni per modificare il modo in cui viene gestita l’importazione.

![](../assets/importing-resources-Importwindow.png)

* Dalla <b>barra sinistra</b>, utilizza il pulsante <b>Ottieni contenuto </b>, quindi seleziona <b>Importa in pila livelli</b> o <b>Importa in risorse</b>. Entrambe le opzioni aprono una finestra di dialogo per la scelta dei file da importare, in cui è possibile individuare e selezionare il file o i file da importare.
  * <b>Importa in pila livelli</b> importa il file per il progetto corrente.
  * <b>Importa in risorse</b> importa il file in modo che sia accessibile da qualsiasi progetto.

![](../assets/Project_CreateNew.png)

* Nel pannello <b>Livelli</b>, se non è stato creato alcun livello, potete usare i collegamenti disponibili per importare un file da usare come base per il materiale.

>[!NOTE]
>
> Le risorse sono collegate e non importate. Di conseguenza, se un file di risorse viene spostato o eliminato, i materiali o i contenuti creati con tale risorsa saranno interessati. Di conseguenza, si consiglia di utilizzare una cartella dedicata per Risorse Sampler.
> 
> Per impostazione predefinita, le risorse incluse in Sampler sono memorizzate in C:\Program Files\Adobe\Adobe Substance 3D Sampler\Resources\assets

## Formati di file supportati

| Tipo | Descrizione |
| --- | --- |
| <b>Bitmap/Immagini</b> (JPEG, PNG, ecc.) | Potete trascinare e rilasciare o importare le bitmap nel pannello <b>Livelli </b>, oppure nei parametri SBSAR o di filtro che consentono l&#39;input di un&#39;immagine. |
| <b>Substance pacchetti</b> (SBSAR) | Puoi importare i file SBSAR nel pannello <b>Risorse </b> o nel pannello <b>Livelli </b>. |
