# Scripting e sviluppo

Adobe Substance 3D Sampler supporta i plug-in personalizzati tramite l’API Python di Sampler. I plug-in possono essere utili per tutti gli utenti di Sampler, dall’automazione della creazione di materiale per librerie di materiali di grandi dimensioni all’esecuzione automatica della configurazione per nuove installazioni o all’aggiunta di nuove funzionalità.

La documentazione completa dell’API è inclusa durante l’installazione di Sampler. Puoi aprire la documentazione delle API da Sampler:

* Utilizza Aiuto > Documentazione Python API... per aprire la documentazione.

* [Gestire i plug-in e gli script installati](manage-installed-plugins-and-scripts.md)
* [Creare un plug-in con Python e QML](create-a-plugin-with-python-and-qml.md)
* [Creare uno script con Python](../scripting-and-development/create-script-with-python/create-a-script-with-python.md)
